# Who Will Win the NBA Title?

A step-by-step, beginner-friendly explanation of a statistical model that forecasts the NBA champion,
with forecasts updated during the 2026-27 season.

- `index.html`: the page (text)
- `data.js`: all the numbers (forecasts, forecast log, back-test of past champions)
- `app.js`: charts and interactive widget
- `style.css`: styles

Static site, no build step: served as is by GitHub Pages.
